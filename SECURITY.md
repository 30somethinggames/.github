# Security

If you've found a vulnerability in a 30somethingGames app, site or service, email **support@30somethinggames.com** with "Security" in the subject. Please don't open a public issue or post about it until we've fixed it.

Include what you found, how to reproduce it, and what someone could do with it. We'll confirm we've received it, keep you posted while we fix it, and credit you when it's fixed if you'd like.
