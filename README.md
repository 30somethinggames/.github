# .github

Org-wide defaults for every 30somethingGames repository: issue forms, the pull request template, `SECURITY.md` and `SUPPORT.md`. GitHub uses a file from here for any repo that doesn't have its own. `profile/README.md` is the org's public page.

This repository is public (GitHub requires it), so nothing private goes in it.

A repo's own `.github/ISSUE_TEMPLATE/` folder, even just a `config.yml`, replaces **all** of these issue forms, so repos don't keep one. Change the forms here.
